## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → PostgREST RPC | Untrusted admin action + passphrase crosses into SECURITY DEFINER functions (generate_round, start_timer, cancel_timer) |
| RPC → round_timers | Server is the sole writer of timer state (RLS allows anon SELECT only) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Elevation of Privilege | new `start_timer` RPC | mitigate | Mirror the verbatim `crypt(p_passphrase, passphrase_hash)` validation from 00004:207-217; RAISE 'Invalid passphrase' before any UPDATE; SECURITY DEFINER + `SET search_path = public, extensions` (no injectable search path) |
| T-09-02 | Tampering | `generate_round` status discriminator | mitigate | Status is derived server-side via `CASE … COALESCE(p_overtime_minutes,0) > 0`; client cannot directly set `status`; existing overtime bounds check (00005) retained |
| T-09-03 | Spoofing / Tampering | `cancel_timer` widened to pending | mitigate | Same passphrase gate already guards cancel_timer; widening the status filter adds no new bypass and no new write path |
| T-09-04 | Denial of Service | repeated `start_timer` / duplicate pending rows | accept | `useTimer` ORDER BY created_at DESC LIMIT 1 + the pending cancel sweep keep state single-rowed; no unbounded growth, low-value target |
| T-09-SC | Tampering | npm/pip/cargo installs | accept | Zero package installs this phase (RESEARCH: no Package Legitimacy Audit needed — all libs already in package.json); no registry/postinstall surface |
